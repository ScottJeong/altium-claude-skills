# 미결선·플로팅 핀 판정 기준

도구가 뱉은 후보를 거르는 표. **이 문서만으로 후보 대부분이 걸러진다.**
여기서 안 걸리는 것만 데이터시트를 판다.

## 즉시 오탐 — 도구의 한계지 결함이 아니다

| 증상 | 왜 오탐인가 |
|---|---|
| `hidden=True` 인 전원핀이 "미결선" | Altium 은 **숨은 핀을 이름으로 자동 연결**한다. 배선이 없어도 정상. 예: 오실레이터 심볼의 `GND` 핀 |
| 핀이 "배선에 안 닿음" | 전원포트에 **직접** 붙었거나 다른 핀과 **직접** 맞닿았을 수 있다. 배선만 보는 검사는 이걸 놓친다 |
| `NC` 이름 핀 | No Connect. 안 붙는 게 정상 |
| 커넥터의 미사용 기능핀 | USB-C 를 전원 전용으로 쓰면 `DP1/DN1/DP2/DN2/SBU1/SBU2` 는 전부 뜬다. 정상 |

**"배선에 안 닿는 핀 N개" 를 결함 수로 보고하지 마라.** 위 네 가지가 다 섞인 숫자다.

## 핀 방향으로 1차 판정

Altium 전기타입(`electrical_name`) 기준.

| 타입 | 플로팅일 때 |
|---|---|
| `Output` | **대개 무해.** 구동원이 부하 없이 떠 있을 뿐 |
| `OpenCollector` / `OpenEmitter` | 무해. 풀업이 없으면 신호가 안 잡힐 뿐 기능 손상 없음 |
| `Passive` | 심볼 제작자가 타입을 안 넣은 경우가 많다. **타입을 믿지 말고 데이터시트를 본다** |
| `HiZ` | 무해 |
| `Input` | **확인 필요.** 내부 풀 유무를 데이터시트에서 본다 |
| `Power` | **확인 필요.** 전원·GND 가 안 붙은 건 대개 진짜 결함 |

주의 — 손으로 만든 심볼은 **전 핀을 `Passive` 로 둔 것**이 흔하다. 그 경우 타입 정보가 없는
것과 같으니 곧장 데이터시트로 간다.

## 데이터시트에서 볼 것

핀 설명표에서 그 핀 행을 찾아 **세 가지**를 본다.

1. **Type 열** — `I` / `O` / `I/O` / `P` / `O/OD` 등
2. **내부 풀 표기** — `(PU)` `(PD)` `Internal pull-up` 같은 것.
   Reset State 열에도 따로 적히는 경우가 있다
3. **비고 문장** — "must be either floating or connecting to GND" 처럼
   **플로팅을 명시 허용**하는 문장이 있으면 그걸로 끝이다

이런 항목을 만나면 판정이 끝난다.

```
<핀>   Type: I (PD)   Reset State: I (PD)
       "must be either floating or connecting to GND"
```

→ 내부 풀다운 + 플로팅 명시 허용. **외부 풀다운 불필요.**

## 부품 종류별 함정

### 버스 스위치 / 아날로그 스위치 (CBT·CBTLV·FSA 계열)

**A/B 단자는 로직 입력이 아니라 패스-FET 단자다.**
"플로팅 CMOS 입력은 관통전류" 규칙이 **적용되지 않는다.**

로직 입력은 `S`(select)·`OE` 뿐이다. 이 둘만 확인하면 된다.

데이터시트에 `unused` / `float` / `left open` 언급이 **아예 없으면**
미사용 채널을 어떻게 하라는 요구가 없다는 뜻이다. 없는 요구를 만들지 마라.

다만 `OE` 에는 대개 이런 문장이 있다:
> *"To ensure the high-impedance OFF-state during power-up or power-down,
> OE should be tied to the VCC through a pull-up resistor."*

`OE` 를 GND 에 직결하면 항상 ON 이다. **양쪽 버스가 같은 보드·같은 레일이면
부분 전원차단 시나리오가 없어 성립한다.** 전원 도메인이 갈리면 그때 문제가 된다.

### 오실레이터

- 4핀 오실레이터의 `GND`/`VDD` 가 **hidden 핀**인 심볼이 흔하다 → 오탐
- `INH`/`OE`/`ST` 같은 인히빗 핀은 **open 이 액티브인 제품이 많다.**
  데이터시트나 사용자 확인 없이 "플로팅 결함" 이라 하지 마라

### PHY / MAC 인터페이스

MAC 쪽에 없는 신호는 PHY 쪽에서 뜬다. 예: MAC 에 `TXER`·`RXER` 가 없으면
PHY 의 그 핀들이 미결선으로 나온다. **인터페이스 정의를 먼저 대조**하면
결함인지 미사용인지 바로 갈린다.

### 커넥터

- 실드 핀을 GND 에 붙일지 `1MΩ ∥ 4.7nF` 로 띄울지는 **설계 결정**이다. 결함 아님
- 스위치형 DC 잭의 스위치 접점은 미사용이면 NC 가 정상
- 다만 **GND 핀이 안 붙은 건 진짜 결함**이다. 실제로 그런 사례가 있었다
  (`DC-JACK 2pi` 의 2·3번 GND 미결선)

## 판정을 못 하겠으면

**`미확인` 으로 남긴다.** 그리고 확인 방법을 같이 적는다.

```
- <부품> <핀번호> <핀이름> — 데이터시트가 로컬에 없다. 내부 풀 유무 미확인
  → 확인: 벤더 데이터시트의 해당 핀 항목, 또는 사용자에게 실물 동작 확인
```

추측으로 결함이라 쓰면 사용자가 없는 문제를 고치러 간다. 그게 제일 나쁜 결과다.
