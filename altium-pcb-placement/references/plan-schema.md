# plan.json 스키마

좌표계: **보드 좌하단 원점, mm, +y 는 위.** Altium 기본과 같다.
부품은 **bbox 좌하단 + 폭/높이**로 적는다 (컴포넌트 원점이 아니라 bbox).

> **bbox 는 반드시 「패드 + 실크 전부」다.** `plan_to_placements.py --libs` 가
> 원점 오차를 계산할 때 쓰는 것과 같은 기준이어야 한다. 패드만 적으면 기준이
> 어긋나 그 차이만큼 부품이 밀린다.
>
> 보드 밖으로 나가는 부품(라이트앵글 커넥터 하우징 등)은 **음수 좌표를 그대로 쓴다.**
> 예: R/A 커넥터를 패드 기준 `x:0, w:9.77` 로 적으면 5.8mm 밀린다.
> 전체 bbox 인 `x:-7.63, w:19.13` 이 맞다 — 하우징이 보드 왼쪽 밖으로 7.63 나간다.

```jsonc
{
  "title": "보드이름 — 배치 가안",
  "board": { "w": 90.0, "h": 100.0 },

  // 배경 색면. 기능 구역을 눈에 보이게 한다
  "zones": [
    { "name": "전원부", "x": 13, "y": 76, "w": 77, "h": 24,
      "color": "#ffe8cc", "lx": 45, "ly": 77.5 }   // lx/ly = 라벨 위치(생략 가능)
  ],

  "parts": [
    { "des": "U2", "label": "설명\n여러 줄 가능",
      "x": 27.0, "y": 29.0, "w": 36.0, "h": 36.0,
      "rot": 270 },                                 // 선택. CCW 도. §5 투입에 그대로 쓰인다

    // 금지구역 — 부품이 아니라 못 쓰는 영역. 주황 점선
    { "des": "", "label": "레버 스윙 46.2", "kind": "keepout",
      "x": 21.9, "y": 27.5, "w": 46.2, "h": 39.0 }
  ],

  // 테스트포인트 줄. dx 또는 dy 하나만 준다
  "tp_banks": [
    { "name": "하단", "x": 29.0, "y": 25.5, "dx": 2.0, "dy": 0, "n": 17 }
  ],

  // 회전한 IC 의 각 변에 뭐가 나오는지. 회전 근거를 도면에 박아 둔다
  "socket_sides": [
    { "box": [27.0, 29.0, 63.0, 65.0],
      "pin1": [61.5, 63.5],
      "labels": {
        "top": "P17 ←── P1  MII",
        "right": "P52 ↓ P68  아날로그",
        "bottom": "P35 ──→ P51  SPI",
        "left": "P18 ↓ P34  버스"
      } }
  ],

  "holes": [ { "x": 14.0, "y": 4.0, "d": 3.2 } ],   // d 생략 시 3.2

  // 주요 신호 흐름. 빨강 점선
  "flows": [
    { "from": [11, 45], "to": [25, 45], "label": "J2↔U2 14넷" }
  ],

  // 판단 근거. 문자열이거나 {text, warn}
  "notes": [
    "보드 90 x 100 / 4층",
    { "text": "소켓 회전 270° — MII 가 좌상 코너에 몰려서", "warn": true }
  ]
}
```

**동작하는 예제가 `examples/plan.example.json` 에 있다.**
거기서 시작해 부품·치수만 바꾸는 게 빠르다.

## 쓰는 법

- `des` 가 빈 문자열이거나 `kind: keepout` 이면 §5 투입에서 제외된다
- `des` 에 `/` 가 들어가면(`D1/D2`) 투입에서 건너뛴다. 그림용 묶음 표기이므로
  확정 단계에서는 나눈다
- 패시브(C/R/L)는 가안에 다 넣지 않는다. **존과 큰 부품만** 넣고,
  디커플링 배치는 라우팅 직전에 따로 정한다
- `label` 에 **공칭 치수인지 실측인지** 적어 두면 나중에 헷갈리지 않는다

## 렌더

```
python scripts/plan_svg.py plan.json -o <출력경로>   # .svg + .png
```

생성 후 **PNG 를 직접 읽는다.** 라벨 겹침·부품과 홀 충돌은 코드로 안 잡힌다.
