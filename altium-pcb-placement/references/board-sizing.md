# 보드 사이즈 역산

## 원칙

**어림하지 않는다. 축별로 치수를 누적한다.**

"이 정도면 되겠지" 로 잡은 사이즈는 늘 크다. 큰 쪽으로 틀리므로 티가 안 나고,
사용자가 "더 줄일 수 있지 않아?" 라고 물어야 발견된다.

## 1. 지배 부품을 먼저 찾는다

한 축은 대개 **부품 하나가 강제**한다.

- 긴 커넥터 (DIN41612 96핀 = 94mm)
- 커넥터를 세로로 두면 그 길이가 Y 를 강제하고, 가로로 두면 X 를 강제한다

**지배 축은 못 줄인다.** `지배부품 길이 + 양끝 여유(각 3mm)` 가 하한이다.
여기를 붙들고 시간 쓰지 말고 **자유로운 축**에서 낭비를 찾는다.

방향 선택이 총면적을 크게 바꾸지 않을 때가 많다. 실증: 96핀 커넥터를
좌변 세로로 두면 90×100 = 9,000mm², 하변 가로로 두면 대략 100×85 = 8,500mm².
차이가 작으면 **사용자 제약(어느 변)이 이긴다.**

## 2. 자유 축을 누적한다

```
X = 커넥터 온보드 깊이
  + 라우팅 채널
  + 소켓/IC 존 (금지구역 + TP 뱅크)
  + 주변 IC
  + 여유
```

**라우팅 채널 폭**은 지나갈 넷 수에서 나온다. 4층 기준 한 층에 트랙/간격
0.2/0.2 면 넷당 0.4mm. 14넷이면 5.6mm, 비아·리턴 여유 포함해 8mm 잡는다.
두 층으로 나누면 절반이지만 가안 단계에서는 한 층 기준으로 잡아 두는 게 안전하다.

**존 폭**은 몸체가 아니라 **금지구역**이다. 테스트 소켓이면 레버 스윙,
커넥터면 결합 여유. 그 바깥에 TP 뱅크가 붙는다.

## 3. 모든 배치에 이유를 대본다

누적을 끝냈으면 부품을 하나씩 짚으며 **"왜 여기?"** 에 답한다.

답이 이것 중 하나여야 한다:
- 보드 변에 있어야 한다 (커넥터)
- 상대 부품 최단 (MDI, 클럭, 디커플링)
- 사용자가 지정했다
- 기구 제약

**"딱히"** 가 나오면 그 부품이 보드를 키우고 있다. 실증: RJ45 를 소켓 대각선에
뒀는데 이유가 없었고, PHY 바로 위로 옮기니 X 가 **120 → 90** 으로 줄었다(-29%).

## 4. 고정 홀 — 대칭이 먼저다

M3 기준 홀 Ø3.2, 키프아웃 Ø6. **중심은 보드 변에서 3.0mm** 를 기본으로 잡는다.

모서리 라운드가 있어도 3.0 이면 안전하다. 모서리 호는 바깥으로 볼록해서
멀어지는 방향이다 — R2 · 홀 (변에서 3,3) 이면 호까지 거리가 3.41mm 로
직선 변까지의 3.0 보다 오히려 멀다. 직각으로 착각해 계산하면 틀린다.

**변에 커넥터가 붙어 있으면 3.0 을 못 지킨다.** 그 변만 물러난다 —
실측 예: 좌변 전체를 R/A 커넥터가 먹고 패드가 x 11.5 까지 와서 좌측 홀은
`x=15` 가 한계였다(패드에서 1.15mm). 우측·상하는 3.0 을 지켰다.
**한 변을 못 지켜도 x 는 두 값, y 도 두 값이면 대칭은 유지된다.**

> **네 홀의 x 좌표는 두 값, y 좌표도 두 값이어야 한다.**
> 즉 `{x1,x2} × {y1,y2}` 직사각 배치. 하나라도 어긋나면 비대칭이다.

비대칭 고정홀은 조립 지그·스페이서·케이스가 안 맞고, 뒤집어 끼우는 사고가 난다.
**부품이 모서리를 먹어서 홀을 못 놓겠으면, 홀을 옮기지 말고 부품을 옮긴다.**

실증 — 이 절차를 만든 세션에서 좌상 모서리에 DC잭이 있어 홀을 `(50,96)` 으로
도망보냈다. 나머지 셋은 `(14,4) (85,4) (85,95)`. 사용자 지적:
*"pcb 홀은 대칭적이어야지"*. DC잭·USB-C 계열을 7mm 오른쪽으로 밀어
`(14,4) (85,4) (85,96) (14,96)` 로 맞췄다. 부품 7개 이동으로 끝났다.

검산은 코드로 한다 — 좌표 집합의 크기가 각각 2인지 본다.

```python
xs = sorted({h['x'] for h in holes}); ys = sorted({h['y'] for h in holes})
assert len(xs) == 2 and len(ys) == 2, f'비대칭 x={xs} y={ys}'
```

## 5. 외곽 모서리는 라운드

직각 모서리는 취급 중 깨지고, 패널 분리 때 크랙이 가고, 사람이 베인다.

**`R` 은 반지름(mm)이다. 기본 R2.** 케이스에 들어가는 보드면 케이스 내측 R 에 맞춘다.
값을 정하기 전에 사용자 관례를 묻는다 — 회사·담당자마다 고정값을 쓴다.

`altium_monkey` 는 `BoardOutlineVertex(..., is_arc=True, center, radius, start, end)`
로 호를 지원한다. 세그먼트 종류는 **시작 꼭짓점에 붙는다** — arc 꼭짓점이 다음
꼭짓점까지 호를 그린다. 완성된 함수는 `scripts/apply_outline.py` 의 `rounded_rect()`.

## 5. 층 수

| 조건 | 층 |
|---|---|
| 저속 · 넷 적음 | 2 |
| 병렬버스·MII 같은 다수 동기 신호, 차동쌍, 테스트포인트 다수 | **4** (SIG-GND-PWR-SIG) |
| 고밀도 BGA, 임피던스 제어 여러 종 | 6+ |

4층이면 **GND 를 통짜로 두는 게 목적**이다. 그걸 쪼개면 4층인 의미가 없다.
차동쌍 아래 GND 가 끊기지 않게 배치 단계에서 미리 경로를 정한다.
